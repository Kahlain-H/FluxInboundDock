## ✅ Installation Terminée !

## 🎯 Scripts de Lancement

### Pour développement (recommandé)
```
Double-cliquez sur: LANCER_SITE.bat
```
- Lance le serveur de développement
- Site accessible sur: http://localhost:3000
- Rechargement automatique des modifications

### Pour compilation
```
Double-cliquez sur: BUILD_SITE.bat
```
- Compile le site pour production
- Génère les fichiers dans le dossier `dist/`

## 🌐 Utilisation sur d'autres PC

### Option 1: Copie complète
1. Copiez tout le dossier `FluxInboundDock` sur l'autre PC
2. Double-cliquez sur `LANCER_SITE.bat`
3. C'est tout ! Node.js portable est inclus

### Option 2: Version compilée uniquement
1. Exécutez `BUILD_SITE.bat` une fois
2. Copiez seulement le dossier `dist/` sur l'autre PC
3. Servez avec n'importe quel serveur web (Apache, IIS, Python, etc.)

## 🔧 Fichiers créés

- `LANCER_SITE.bat` - Lance le serveur de dev
- `BUILD_SITE.bat` - Compile le site
- `install-deps.bat` - Réinstalle les dépendances si nécessaire
- `node-v20.18.0-win-x64/` - Node.js portable inclus
- `node_modules/` - Dépendances installées
