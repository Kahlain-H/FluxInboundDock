## 🚨 **PROCÉDURES DE SÉCURITÉ**

### **AVANT CHAQUE MODIFICATION:**
1. **Double-cliquer sur `FAIRE_BACKUP.ps1`**
2. Attendre la confirmation de sauvegarde
3. Procéder aux modifications
4. Tester le résultat

### **EN CAS DE PROBLÈME:**
1. **Double-cliquer sur `RESTAURER_BACKUP.ps1`**
2. Choisir la sauvegarde à restaurer
3. Confirmer la restauration
4. Tester que tout fonctionne

### **EN CAS D'URGENCE TOTALE:**
1. Aller dans `BACKUPS/2025-11-07_VERSION_STABLE/`
2. Copier `flux-sections-excel-style.html`
3. Coller dans le dossier principal
4. Remplacer le fichier
5. **TOUT SERA RESTAURÉ**
